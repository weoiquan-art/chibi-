# Q版统一视频提示词模板

用户交代剧情后要求视频提示词时，**先按照本模板生成**；要求统一模板、LibTV 式镜头卡、逐镜交付或全片逐生成单元交付时同样使用。普通未走剧情转 Prompt 分支的日常片段可沿用主入口轻量结构。继承成功稿时使用其原结构，只改用户要求及必要联动。导演理由、整片位置、资产缺口和草案状态写在复制区外；正式正文删除未使用的占位行。

每次生成独立写一份，单镜只留一张卡。参考以实际已检查素材和当前平台绑定为准；未知引用只能用于明确标注的规划草案，不能称为可直接提交。无参考素材时如实写明，若缺少必须的角色身份资产则先交接，不重新设计四小只。

```text
【本次生成】
片段编号：〔G编号；单段可简写〕。〔已知模型／版本〕，〔本次时长〕，〔画幅〕。

【参考素材职责】
〔实际角色引用〕：对应〔本次角色＋本体／Q版形态〕，锁定〔身份、身体结构、比例、服装等实际职责；身高仅在已知且影响互动时写〕；不继承〔白底、原姿势或构图等必要项〕。
〔实际道具／场景引用，确有时〕：锁定〔本片所需属性〕，〔必要的不继承项〕。
〔实际关键帧／站位／动作／声音参考，确有时〕：用于〔对应镜号与具体职责〕；角色身份以〔实际身份资料〕为准。
〔仅当同一属性冲突时，说明对应参考的优先级；没有参考的项目删去〕。

【全局要求】
正向成像与角色固定层：〔继承本片或 BASE 已定的成像媒介、拍摄载体、各形态质感、角色比例与真实接触；不将 Q版描边／比例套给本体〕。
第一帧空间与连续性：〔摄影机所在位置与朝向、角色分布和起始状态、关键道具与必要路径；光线归属具体空间〕。
实际出镜：〔只列本次主线角色与实体数量；明确指定后景 OB 时才另列〕。
声音与字幕：〔各实际角色及形态的对白／拟声权限、音乐／环境声／字幕要求〕。

【分镜拆解】
镜〔编号〕｜〔预计时长；按需保留本单元局部区间或明确相对顺序〕｜〔景别〕｜〔机位·拍法〕
画面：〔第一可见帧的角色、主体占位与目标关系〕。〔沿时间写行动／可见表演、协作双方响应、接触、镜头因果及必要环境反馈〕。〔结果与仍持续的持握、接触、运动或情绪〕。
台词／拟声／声音：〔实际发声角色、已获准的逐字台词或固定拟声、语气／距离、发声先后及必要口型；或无对白＋具体环境／动作声〕。
出片要点：〔本镜最不能丢的 1–3 项可见或可听结果〕。

〔同一镜内使用“阶段”或局部区间承接动作，不写成切镜；实际换镜时明确“切至镜……”，继续下一张镜头卡。〕

【反向约束与失败保险】
〔少量保护本片最脆弱的身份／形态、实体数量、道具、动作时序、风格或镜头因果；不复制通用负面词，不与正向正文重复〕。
```

固定的是外层组织，不是角色人数、镜头数、参考图数或动作密度。默认 15 秒只适用于未指定时长的新日常片段；用户已定时长及 BASE 优先。时间区间是内容安排，不承诺模型逐秒执行。

声音按实际角色与形态资料；四小只新稿沿用固定拟声，Q版 Sera 使用 `Sela`，Q版糯糯使用 `糯糯～`。本体对白按本片明确权限与语言，新 Q版不编造拟声。不把作者的语气符号、思想说明或“先按模板”的制作备注写入视频正文。可以全段安静，不为证明角色存在而每人轮流发声。

参考引用须来自实际已查看文件及真实绑定。只有用户提供的图号时写图一／图二，不虚构素材 key。关键身份缺失时标明待绑定草案；普通环境与道具不因模板有栏位而自动增加资产。每镜时长和区间跨度保持一致，不混用整片时间与局部时间，也不承诺模型精确按秒服从。

动作段可保留必要的连续细节；安静段以有意义的观察、停顿、接触和反应成立。摄影机、角色、道具与环境共同证明当前事件，不拆成互相重复的说明表。
