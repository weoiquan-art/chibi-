# 无厘头剧情：认真情绪与荒唐应对

用于新日常主题、无厘头剧情、Q 版以奇怪方式表达情绪，以及 15 秒或 1–2 分钟故事。按 JIN 指定的刘镇伟式无厘头“剧情逻辑”提炼方法，不模仿具体电影、台词、角色或桥段。由 Chibi 独立使用，不开启额外剧情 Agent 或要求读取外部 Skill。

## 先决定交付到哪一步

只要剧情时，只交目标、动作因果、升级与结尾，不提前设计景别、运镜或视频 Prompt。用户已有剧情则继承，不借参考方法另写一部故事；用户同时授权生成提示词时，继续执行主入口的剧情转 Prompt 分支。

## 从角色认真想要的东西出发

先确定一个情绪诉求与可见小目标：想得到认可、保住好吃的、逃过收拾、争回一口气、让伙伴注意自己等。没有具体事件引发的“突然生气／突然报复”不能承担转折。

沿着 `具体刺激 → 情绪变化 → 角色选择 → 可见结果 → 下一行动` 推进。荒唐可以来自误会、字面理解、过度反应、错误尺度、耍小聪明或逃避办法；不把无厘头写成随机事件。

一种可用结构是：`正常小目标 → 小意外 → 错误但一本正经的解决办法 → 为维持同一逻辑而升级 → 后果越来越荒唐 → 回扣最初目标或情绪诉求`。这些是功能，可以合并，不是六个镜头或必填六段。

角色本人认真，允许得意、委屈、不服气、心软、迟疑；不向观众承认“这很荒谬”。用看见、误判、试做、结果与反应让观众读懂，不依赖解释性旁白、字幕或 Q 版完整对白。

## 常用喜剧互动与升级

- **洛洛处罚糯糯**是这组故事的常用走向：洛洛认真管，糯糯认真想躲、装乖、讨好、藏证据或钻空子，应对带出新麻烦与露馅。洛洛可以一直占上风；不强制双方轮流吃瘪。
- 起因也可以是糯糯想认真做好一件事，受到刺激后不服气、换办法证明自己；不强制捣蛋开场，不将每集写成品德教育或温馨和解。
- Q 版角色有自己的行动权。受到具体刺激后，才产生生气、反击或补救；本体、第三方和其他 Q 版按事件参与，不负责机械轮流表演。
- 每次升级沿同一问题展开：加大投入、扩大范围、修补漏洞、换一种同目标的办法，或利用前一结果反击。重复段落必须改变方法、情绪、后果或对方反应。
- 结尾让前面的目标、道具、规则或行动派上用场。目标可以荒唐实现、失败、被误解或反噬；不靠无关新道具、随机摔倒、突然醒来收尾。

人物关系只设到足够解释本集，不补造亲属、主人宠物或复杂本体关系。剧情中的处罚通过补救任务、限制、追赶、装乖和声画反差等表现；遵守本次“画面不真正打糯糯”的要求，不固定成某一个替代桥段。

## 身体物理、有限奇幻与角色边界

身体与道具保持重量、支撑、持握、接触和连续运动。JIN 允许接近例子风格的有限奇幻；选用某个小能力时，只补本段必要的触发、作用对象、去向与结果，不临时增加万能能力来解围。

压扁、拉伸、肚子膨胀、变球、弹簧化或吸入小容器等属于待验证的具体视觉实现；先有样片与用户验收，再决定是否采用或升级经验。Q 版可爱、夸张情绪不等于这些身体变化已经稳定。

按当前资料区分角色。菲比可以主动实践，糯糯可以认真投入或耍小聪明，Sera 可以安静地把错误办法做得更彻底；这些是表演选项，不是固定工位。捣蛋剧情不把糯糯永久改成失控、总摔倒的角色，也不让 Sera 每次负责恢复理性。声音继续按本次身份权限，不复制案例对白。

## 两种篇幅与交付

- **15 秒单条**：围绕一个小目标、一条错误办法和一个主笑点，通常一到两次升级就足够；不为凑结构硬加场景或人物。
- **1–2 分钟故事**：以多个 15–30 秒剧情段推进同一目标，每段有小变化或小笑点，后一段承接前一后果，整片结尾回扣主线。用户明确要独立段子合集时再允许各段独立。

短条交“主题／目标与情绪／可见动作因果／升级／结尾”；长故事增加紧凑剧情段表与总时长。剧情段不等于镜头或一次生成单元。只要主题候选时用简述，不展开制作计划；用户已授权直接到 Prompt 时不逐环节停下确认。

内部检查每次行动是否有上一因、重复是否有新变化、回扣是否接住前面、角色是否认真且有区别、动作是否能装入时长。只修实际问题，不输出重复检查报告。这是用户确认的创作方向，不宣称已通过真实成片验证。
