# 已确认爆款基线

本文件只记录创作者明确说过的爆款 / viral Q版内容，以及当时已经确认的观察。

不要因为某个元素出现在爆款里，就自动把它升级成全局规则。

---

## 1. 披萨外送菲比

### 状态

- 创作者自己的实际作品；
- 被创作者明确描述为之前的爆款 / viral hit；
- 约 15 秒竖屏内容。

### 核心事件

```text
主人在家门口
→ 透过门下部透明区域看见菲比
→ 菲比穿小外送服，手里只有一个披萨盒
→ 敲门两次
→ 主人接过同一个披萨盒
→ 菲比立刻沿石路跑掉
→ 跑掉以后才喊“菲比啾比！！”
→ 声音随着距离变远
→ POV 打开刚才同一个披萨盒
→ 里面只剩一块三角形披萨
→ 关盒
→ 抬头看见小小的菲比还在远处逃跑
```

### 已确认的制作事实

- 画面主体是菲比 + POV 双手；
- 只有一个披萨盒；
- 披萨盒只交接一次；
- 菲比只跑掉一次，不返回、不复制；
- 叫声发生在开始逃跑以后；
- POV 的动作有因果：接盒 → 开盒 → 关盒 → 抬头；
- 结尾的反转来自“外送来的披萨只剩一块”。

### 当前可学习的方向

这里最值得保留的是**清楚、容易理解的单一事件链**：

> 外送 → 交接 → 离开 → 打开 → 发现异常 → 看向逃跑角色。

这个案例证明：Q版短视频可以用一个非常日常、非常小的事件，加一个容易读懂的结果反转成立。

但不要总结成：

- 所有 Q版视频都需要偷吃；
- 所有 Q版视频都需要跑掉；
- 所有爆款都必须有反转；
- 第一人称 POV 本身就是爆款原因。

这些都没有被单独验证。

## 2. 欢迎回家：糯糯 + 菲比 + Sera

### 状态

- 创作者自己的实际作品；
- 被创作者明确描述为最喜欢的作品之一，并且是爆款；
- 约 10 秒；
- 三个 Q版角色同时出现。

### 核心事件

主人回家以后，三个角色不是一起做相同动作，而是各自完成不同的小照顾：

- **糯糯 / Nuonuo**：抱着一个比自己脸还大的拖鞋，身体因为拖鞋重量摇晃，把拖鞋放到主人脚边；
- **菲比 / Phoebe**：用更主动、更黏人的方式靠近主人，包括弹跳 / 滑到脚边，并主动寻求摸摸；
- **Sera**：比较安静，把主人的钥匙放回小钥匙盘；
- 主人最后摸三个角色；
- 三个角色在暖光里形成欢迎主人回家的收尾画面。

### 已确认的制作事实

- 恰好三个 Q版角色；
- 三个角色承担不同的行为职责；
- 不是同步跳舞、同步叫、同步卖萌；
- 糯糯的大拖鞋有明显的体型 / 重量关系；
- 菲比更主动亲近；
- Sera 的行为更安静、更生活化；
- 没有强行设计剧情反转；
- 整个满足感来自一连串很小的“欢迎主人 / 照顾主人”动作。

### 当前可学习的方向

这个爆款证明：

> **没有反转也可以成立。**

如果角色连续做的小动作本身已经让观众感觉：

> “它们真的住在这里，而且知道主人回来了。”

就不需要额外塞一个反派、事故或结尾翻转。

同时，多角色内容的差异可以来自：

> **每个角色选择做不同的事情。**

而不是只靠颜色、外观或台词区别。

# 两条爆款共同支持什么

目前可以较有信心保留的共同方向：

1. **事件很小，但必须具体。**
2. **角色行为要像它真的生活在这个环境里。**
3. **角色的可爱来自行为和体型 / 物理关系，不只是表情。**
4. **题材不需要复杂世界观才能成立。**
5. **反转是可选结构，不是硬规则。**
6. **多角色最好通过不同的行为职责区分。**

仍然不要把这些爆款当成公式复制。

新的题材应该问：

> “还能有什么新的生活事件，让这些 Q版角色自然做出属于自己的行为？”
