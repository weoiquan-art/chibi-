# 已验证与待验证的内容结构

这些结构来自 JIN 的高满意或高表现样本。它们是选题工具，不是每条视频必须套用的公式。

## A｜治愈观察／照顾

适合睡着、等待、回家、盖被、降低噪音等低能量内容。

```text
发现安静状态
→ 放轻动作靠近
→ 做一个不打扰角色的照顾动作
→ 中途停顿确认
→ 角色出现微小无意识反馈
→ 环境被安静处理
→ 稳定收尾
```

张力来自“怕打扰”，微小反馈通常比大表情更有效。可以完全没有角色拟声。

## B｜交付／离场／揭示

来自菲比外送类高表现样本。

```text
奇怪但一眼能懂的身份或任务
→ 围绕一个主道具完成一次交接
→ 角色离场
→ POV 检查同一主道具
→ 小反转或奖励被揭示
→ 再看角色远去
```

保护：一个主道具、一次交接、先离场后揭示、反转一眼可懂。

## C｜多人欢迎／共同照顾

多个角色围绕同一目标各做不同贡献：有人抢先制造能量，有人认真递物，有人安静收尾。价值来自行为选择差异，而不是所有角色一起喊或同步动作。

延长内容时优先深化搬、跑、滑、接、摸、放下等过程和互动反馈，不强加第二条剧情线。

## D｜监控／意外目击／追逐

JIN 已观察到监控视角与突发追逐类内容具有高传播潜力，但目前证据不足以升级为固定公式，状态为 **TEST**。

可探索的核心不是“必须追逐”，而是：稳定客观视角先建立正常空间，随后出现一个违反预期且容易读懂的事件，观众像偶然目击者一样看完整个升级过程。

应用前先确认：

- 固定／监控视角是否真的服务笑点或意外感；
- 角色路线在画面中是否可读；
- 追逐是否只有一个明确目标；
- 背景空间是否足以承载进入、经过和离开。

## 选择原则

先问当前题材需要什么体验，再选结构：

- 想让观众放松、心软：A。
- 想制造小惊喜与回看：B。
- 想展现角色关系：C。
- 想制造偶然目击和快速升级：可测试 D。

题材不匹配时不使用。不要为了“15 秒必须反转”破坏一个本来成立的温柔事件。
