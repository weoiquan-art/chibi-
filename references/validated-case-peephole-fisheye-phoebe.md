## 实际成片可确认的结果

- 全程维持固定圆形猫眼构图与深色镜片边框，没有用切镜完成主要变化。
- 菲比从中央完整身体开始，向画面左侧离开，随后从边缘重新探头。
- 菲比重新进入后逐渐靠近镜片；脸部随距离产生连续的鱼眼放大。
- 中段形成眼睛与脸颊占据圆形视野的极近大脸构图。
- 结尾菲比后退，恢复完整身体并回到中央等待。
- 背景与猫眼边框基本稳定，画面大小变化主要由角色靠近和后退形成。
- 音频信号中可识别约五个主要短发声段；提示词要求七次，模型进行了节奏合并，但用户仍确认整体效果很好。
- 成片音高明显偏高：估算主要发声的基频中位约 571 Hz，约 10–90 百分位为 381–667 Hz。该数据说明最终声音确实处于清亮高音区，但不能单凭成片证明声音由哪项提示词或哪种后期算法单独造成。
- 未进行逐音节人工听写，因此不把每次发声是否逐字命中“菲比？”写成确定结论。

## 可复用结论

### 1. 复刻参考视频时先拆“画面为何变化”

本案例最重要的因果是：

```text
猫眼与摄影机固定
→ 角色主动横向离开与重新探头
→ 角色主动靠近镜片
→ 距离变化产生连续鱼眼放大
→ 角色主动后退恢复完整身体
```

若只写“脸变大、鱼眼特写”，模型可能用镜头缩放或脸部变形代替身体靠近。把摄影机固定、角色位移和光学结果分开写，才保留了参考视频的动作机制。

### 2. 换角色时保留技术结构，替换角色字段

可保留：

- 目标时长与一镜到底；
- 猫眼／鱼眼摄影机载体；
- 固定镜头；
- 中央等待 → 离开 → 边缘探头 → 靠近 → 极近大脸 → 后退复位；
- 短音重复与声音随距离变化；
- 中央完整身体结束构图。

必须替换：

- 角色身份与参考图职责；
- 专属拟声词；
- 固定音色；
- 走路速度、犹豫程度、眼神和微表情等性格表演。

案例动作和猫眼玩法不是任何角色的固定 Canon。

### 3. 声音应保存“节奏功能”，不冻结精确次数

本案例中，七次书面发声被成片合并为约五个主要发声段，但重复短音、高音区、轻起音、疑问上扬和距离变化仍共同形成了可爱感。因此：

- 精确发声次数可以作为控制目标，不应仅凭这次成功升级为所有模型都必须逐次命中的硬规则；
- 更稳定的核心是“同一句短音反复出现、彼此错开、跟随可见动作、靠近时更近更清晰、退远时变轻”；
- 使用固定 IP 时，把原视频台词的功能映射到角色专属拟声词，不让角色为了复刻而说正常人类语言。

### 4. 屏幕录制外壳不是复刻内容

参考视频中的手机状态栏、播放器按钮、字幕或平台界面属于屏幕录制与播放外壳。复刻时只提取圆形猫眼、场景、角色动作、声音节奏和光学变化，不把界面元素继承进生成画面。

## 证据边界

这是“参考视频＋改写 Prompt＋实际成片＋用户正向反馈”的单次成功案例。它足以作为猫眼／固定鱼眼单角色复刻的可复用 BASE，也支持将参考视频拆成摄影机、角色运动、光学结果与声音节奏的工作方式。

它尚不能证明：

- 七次发声在其他模型中一定会逐次执行；
- 同一结构换成糯糯或 Sera 后会得到完全相同的表现；
- 高音区、问号、角色外观或动作中的某一项是可爱声音的唯一原因；
- 所有参考视频都可以只用同样的字段完成复刻。

后续糯糯与 Sera 版本应按 Minimal-Delta Mode 保留技术结构，只替换角色身份、拟声词、音色和必要的性格表演，并分别等待实际成片验证。
