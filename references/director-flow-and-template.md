# Q版镜头与模板知识补充

用于推敲切镜、一镜到底、复杂构图或解释拍法。它是同步到 chibi 的本地知识，不是第二套创作流程；读取后把当前问题的答案写回原有 Prompt，无需读取通用视频 Skill 或启动分工 Agent。

## 让每个镜头承担具体任务

从当前事件确定观众此刻需要看清什么：空间关系、行动过程、双方接触、表情反应或结果。删去一镜不会损失信息、情绪或必要节奏时，考虑合并。文字分镜分配注意力和先后，不自动要求制作分镜图片。

- 切镜用于新信息、关键反应、空间／时间转换，或确有必要的生成可控性。不要为了覆盖景别表增加切镜。
- 一镜到底用于保留实时互动、路径与动作因果；镜内仍需人物走位、视线与注意力交接。
- 景别变化可以来自角色靠近、POV 身体行为或镜头操作，写明真正的变化主体。当前载体是手机 POV 时，保持该载体可完成的拍法。
- 用户询问镜头方案时给出本片具体镜头数、剪切次数与关键镜内变化，并简述原因；只要 Prompt 时，把判断落实在画面里即可。

## 构图让动作证据看得见

明确主体与目标在画面的哪一侧、相距多远、朝向哪里，关键接触能否同框，谁遮挡谁，何时揭示。前中后景、留白和引导线只在承担信息或情绪作用时使用。

景别必须容纳当前证据：想看脚步承重就保留脚与地面，想看递接就保留双方手和物件；面部近景不能同时要求看清画外完整动作。需要强调脸部反应时，先保证必要空间已经建立。

## 把人物、场景与动作写在同一时间线上

从第一可见状态写起：身体信号／发力 → 运动过程 → 接触与响应 → 继承下去的结果。角色、道具、摄影机与环境共同证明这一事件。安静表演只写有意义的注视、呼吸、停顿或接触，不展开无关全身动作。

动作密度由事件决定，不移植其他作品的角色、武器、光效、破坏规模、固定出手次数或精确帧数。多人协作、承重与接触不清时补读多人动作知识；相关内容已在上下文中则直接使用。

## 用模板发现实际缺口

已有剧情转 Prompt、或用户要求结构化分镜输出时，先使用主入口列出的统一模板；它负责组织信息，不负责制造剧情或资产。继承已接受 BASE 时保留原结构。剧情段、实际镜头与生成单元分别判断：含硬切的蒙太奇拆出内部镜号，同一镜的景别变化则写明移动／转向过程，不能仅靠标题变换景别。

| 字段缺口 | 处理 |
|---|---|
| 当前已经给出的角色、事件、声音、参考映射 | 直接继承，不重复问 |
| 景别、构图、机位或节奏 | 提出具体执行方案，不改变已定事件 |
| 身份、关键选择、结尾或影响接触／到达／揭示的空间事实 | 集中提出必要问题，沿用主入口的提问上限 |
| 尚未提供或未检查的参考 | 标明草案与待绑定项，不编造实际图号、素材 key 或验收结果 |

仅使用当前真实存在的角色、道具、场景、关键帧和声音资料。没有的参考类别删去；普通道具或环境不因出现空栏就要求生图。导演理由放在复制区外，正文保留模型能执行的可见、可听内容。

这份补充是写作方法，尚不代表每种拍法已经通过真实成片验证。角色及形态、发声权限、POV、已接受 BASE 和案例证据状态沿用本片规则；不从例子自动继承普通对白、身体变形或特定画风。
