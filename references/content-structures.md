# Q版内容结构与节奏

2026-10-22 从 SKILL.md 搬来，正文原样，只改了一处指向：原文“按上方分流读取”改成指向长故事知识文件。

下面的“当前生产经验”来自用户已经实际生成、并明确反馈为喜欢或爆款的样本。它们属于当前系列的高价值增量证据，但不意味着所有题材都必须套同一个结构。

## 15 秒默认节奏

当用户没有另行指定且目标约为 15 秒时，按实际事件分配动作／状态阶段。原经验中的 **5–7 个阶段**可作容量参考，不是数量配额，更不等于 5–7 个剪辑镜头。

一种可用思考方式：

```text
建立状态 / 预期
→ 第一次行动
→ 发生阻力、异常或第二次行为
→ 升级 / 反转 / 情绪加深
→ 角色即时反应
→ 收尾动作
→ 稳定定格 / 记忆点
```

允许合并节点。若内容简单，不为了凑数量硬塞事件。

约 8–10 秒时，优先单一情绪弧线和 3–5 个动作阶段；不要机械加入完整反转。

较长内容按信息、空间、时间与制作条件决定切镜，不因超过 30 秒就自动切镜。完整长故事读 [长故事知识](long-story-knowledge.md)。

### 策划秒数与模型时间控制分层

- **策划层**：先为动作／状态阶段估算约几秒，用来判断 15 秒是否装得下、生成要拆几段、剪辑怎样组合；这些秒数由策划者掌握。
- **提示词层**：时间区间是可选控制，按事件保留区间或明确相对顺序；不强制逐秒拆，也不因动作复杂就删除有用区间。镜内用“阶段”承接，真正切镜才新建镜号；区间与帧数不承诺模型精确服从。
- 同地点、同一 POV 的连续互动可作为一段生成；多个片段共同完成故事时，再读本地长故事知识安排共享状态与接续。动作阶段、实际镜头、一次生成的片段分别判断，不用它们互相代替。

策划表中的秒数仍需覆盖目标成片长度；删掉模型 Prompt 中的时间戳，不等于放弃时长策划。

### 从 10 秒加强到 15 秒时，不要机械增加剧情

当前《欢迎回家》10 秒成功样本与后来提出的 15 秒加强方向说明：一个 10 秒结构已经有效时，延长到 15 秒优先做的是：

- 补足搬、跑、滑、接、摸、放下等动作的中间状态；
- 增加角色之间的真实接触或 POV 回应；
- 给微表情、犹豫、确认、减速、放松留时间；
- 让每个角色的行为选择更完整。

不要为了“15 秒必须有反转”硬加与主题无关的新剧情。

## 三种当前高价值内容结构

以下来自用户实际高满意 / 爆款样本。把它们当作可选结构库，不强制所有视频使用。

### A. 治愈观察 / 照顾型

适合“回家发现角色睡着”等低能量主题。

结构可为：

```text
进入空间并发现安静状态
→ 放轻动作靠近观察
→ 发起一个不打扰角色的照顾动作
→ 中途停顿确认没有吵醒
→ 角色出现微小无意识反馈
→ 处理环境噪音 / 光源
→ 回到角色身上安静定格
```

关键经验：

- 不需要强行反转；
- 张力来自“怕吵醒她”的动作克制；
- 微反馈比大表情重要，例如抓被角、呼吸变化、身体轻轻缩一下；
- 环境声可以承担主要音频叙事；
- 结尾通过关电视、降噪、降低动作强度完成情绪收束。

### B. 交付 → 离场 → 揭示反转型

当前披萨外送菲比爆款样本的有效结构：

```text
奇怪但一眼可懂的角色身份 / 任务出现
→ 单一主道具完成一次交接
→ 角色迅速离场
→ POV 二次检查同一主道具
→ 出现一眼可懂的小反转
→ POV 再抬头看角色远去
```

关键经验：

- 前 1–2 秒就让观众看懂“奇怪身份 / 奇怪任务”；
- 全片围绕一个主道具，避免支线抢焦；
- 角色先离场，再揭示道具里的反转，会产生更好的余韵；
- 反转用视觉证据呈现，不用台词解释；
- 角色从近到远的移动可同时带动声音距离变化；
- 结尾回到角色小小背影，形成完整闭环。

### C. 多角色欢迎回家 / 连续照顾型

历史三角色 10 秒《欢迎回家》爆款样本显示：欢迎主题可凭**连续被照顾**形成满足感。15 秒无反转版本是沿此结构提出的加强方案，不能仅凭稿件断言其成片表现。四小只版本应增加第四种行为选择，而不是复制前三人的动作。

结构可为：

```text
开门即看到角色已经在等待
→ 角色 A 做最直接的照顾动作
→ 角色 B 用更活跃 / 搞笑的方式加入
→ POV 对角色做真实回应
→ 角色 C 用克制、细心的动作补上照顾
→ 所有主线角色以不同反应接受 POV 回应
→ 形成清楚、温暖的多人结束构图
```

关键经验：

- “欢迎回家”不要只靠挥手或发声，要通过可见的照顾动作发生；
- POV 的摸头、接物等回应能显著增强“我真的回家了”的代入感；
- 多角色分别做不同事情，比同时做同一动作更有角色感；
- 结尾所有主线角色以不同姿态围住 POV 的稳定构图本身就是记忆点；
- 没有反转也可以成立，只要小奖励动作连续发生。

## 反转与社交媒体记忆点

约 15 秒且内容允许时，可使用：

```text
建立预期 A
→ 实际发生 B
→ 角色反应或视觉证据确认 B
```

反转不是强制项。

先判断内容靠什么成立：

- 靠视觉反差 / 小恶作剧 → 可以使用反转；
- 靠被照顾 / 治愈 / 微表演 → 不强行反转；
- 靠角色动作魅力 → 保持单一弧线也可以。

结尾优先留下一个容易读懂的状态：

- 明确表情 / 姿态；
- 失败后的尴尬停顿；
- 突然安静；
- 角色看向镜头；
- 小动作收尾；
- 远去的小背影；
- 多角色稳定欢迎构图；
- 可自然循环回开头的状态。
