# JIN Q版四小只固定角色圣经

> 状态：用户已确认。用于新聊天中的角色身份、行为、拟声词与默认出镜选择。

## 权威与适用范围

本文件只负责 Q版菲比、糯糯、Sera、咕嘎。用户在当前任务中明确给出的参考图映射、角色增减或临时表演要求，高于这里的默认值。

常用参考图顺序为：图一菲比、图二糯糯、图三Sera、图四咕嘎。只有在用户没有另行标注且输入确实符合这一顺序时才能沿用；不得靠猜测交换身份。

## 默认出镜选择

- 用户说“四小只”“四个一起”或明确列出四人：四人都是主线活动角色。
- 用户只点名其中一人、两人或三人：只使用被点名角色，不自动补齐四人。
- 当前请求没有点名的角色，不得因为旧模板、案例 Prompt、上一版本或参考图里曾出现而自动继承进主线；只有用户明确要求后景 OB / IP 活水印时才允许作为背景存在。
- 用户明确要求某人充当后景 OB、彩蛋或 IP 活水印：该角色退出主线分工，只做低抢戏背景行为。
- Sera 是四小只正式成员，不默认成为后景 OB。
- 无法从当前输入唯一确定“她们”“三小只”指谁，且选择会改变成片时，先简短确认。

## 共同视觉固定层

四人都是现实空间中的 2.5D 赛璐璐 Q版实体角色，而非贴纸、平面叠图、真人儿童或写实毛绒角色。

- 保留参考图身份、脸、发型、服装、配件、身体比例及原有身体结构；
- 圆润实体厚度、清晰粗黑描边、简化动漫块面头发；
- 扁平干净上色、低阴影；
- 与真实环境光统一，有接地阴影、接触阴影、真实重量与物理接触；
- 常用头身比约 1:2、巴掌大小、通透大眼睛；具体仍以对应参考图为准；
- 不继承参考图白底、原姿势和原构图；
- 不增加参考图中不存在的肢体，不交换任何角色身份。

## 菲比

性格：最主动、元气、活泼、兴奋，通常最先对事件作出直接行动。

表演倾向：抢先行动、快速靠近目标、兴奋蹦跳、举手、主动争取 POV 回应。动作幅度可以较大，但具体动作由当前题材和用户要求决定；每个高能动作都必须具有蓄力、运动、落地或接触、减速和稳定结果，不重复同一特技，不瞬移。

拟声词：`菲比啾比～～`、`菲比！`

音色：元气、活泼、兴奋。

## 案例动作不是角色硬绑定 Canon

前空翻、滑铲、从遮挡物后突然蹦出等，都是某些成功 Prompt 或具体题材使用过的**案例动作**，不是任何角色每条视频都应自动执行的固定 Canon。

- 菲比性格 Canon 是主动、元气、兴奋和动作能量较高，不等于默认前空翻或滑铲；
- 只有用户本次明确点名该动作，或所选 BASE 本来就包含且用户要求保留时，才继承前空翻、滑铲等具体案例动作；
- 用户要求“保持结构只换动作”时，被换掉的案例动作不得以角色习惯为理由重新加入；
- 设计全新题材时可以把这些动作当作候选参考，但必须服务当前事件、空间和时长，不得机械复用；
- 其他角色的历史动作同样遵守此规则：案例证明动作曾经可用，不代表动作与角色永久绑定。

## 糯糯

性格：软糯、认真、温柔、反应慢半拍，努力完成事情时会显得稍微笨拙但不失控。

表演倾向：搬递物件、抱紧道具、认真迈小短腿、等待表扬、眯眼接受摸头、慢半拍理解反转。

拟声词：`糯糯～`

音色：软糯、轻柔、可爱。

### 糯糯“摇摇晃晃”的固定含义

当糯糯搬着接近或大于上半身体积的物件时：

- 物件重量让上半身轻微后仰；
- 小短腿交替迈步，身体与道具一起左右轻轻摆动；
- 双脚始终能踩稳，移动路径连续；
- 到达目标后先减速、重新找回重心、把物件放稳，最后才松手；
- 这是受重量影响的可爱、受控摇晃，不是踉跄、打滑、醉酒、濒临摔倒或夸张失衡。

若用户要求“保留糯糯原本的摇摇晃晃”，必须使用这一物理过程，不得随意改写成其他摇晃方式。

## Q版 Sera

性格：温柔、安静、细心、克制，不靠争抢视觉中心表现存在感。

表演倾向：先观察再行动，扶稳物件、接过并收好物品、整理、确认、照顾、轻轻靠近掌心、最后点头。她可以成为主行动者，但动作仍保持安静、准确和有目的。

拟声词：`Sela`（JIN 于 2026-09-25 确认此为今后固定读法；旧 10 秒原稿里的“selasela”只作为历史原文保留，不自动进入新稿。作者写出的 `～` 表示语气，不是拟声词字面部分。）

音色：温柔、安静、软萌。

当 Sera 出现晕船、疲惫、倚靠等状态时，先写身体所处空间、朝向、支撑点与重心，再写“难受”。例如船上晕船：身体和双脚位于船内，背对或侧对镜头，上半身倚靠船沿，双手或前臂支撑，身体随船轻晃但重心留在船内。

## 咕嘎

性格：好动、调皮、直接，带有弹簧感和恶作剧式活力。

表演倾向：突然从遮挡物后蹦出、半拍后跟进菲比、踮脚、探头、短促弹跳、得意停顿。动作可以快，但必须看到起跳或发力、运动轨迹、落地反作用和稳定结果。

拟声词：`咕嘎`、`咕咕嘎嘎！`

音色：活泼、调皮、有弹性。

## 四人差异化

菲比与咕嘎都好动，但不能成为复制动作：

- 菲比偏主动抢先、兴奋地直奔目标；
- 咕嘎偏调皮追加、突然蹦出、弹簧感和恶作剧反应。

糯糯与 Sera 都温柔，但不能成为复制动作：

- 糯糯通过认真用力、慢半拍、道具重量和期待回应表现可爱；
- Sera通过观察、扶稳、整理、确认与克制收尾表现温柔。

四人共同出镜时，不整齐同步挥手、蹦跳、转头或发声。围绕同一核心事件，让每人承担不同的行动、协助、阻力、反应或收尾。

## 发声边界

四人都不说正常完整人类语言，只使用自己的固定拟声词。不得交换拟声词。

声音根据动作和空间距离错开安排，不要为了证明四人都在场而让四个声音挤在同一时间片。角色可以保持安静，只要她／他的动作参与仍然清楚。
